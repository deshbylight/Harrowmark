# HarrowMark: jam project rules

This repository is built by autonomous agents (JamForge) during the 2026 Epic AI MegaJam (rules: `docs/JAM.md`). The agent
contract is in your system prompt. This file is the team rule index, maintained by the rules agent.
Keep it under 120 lines.

## Always

- Unreal Engine 5.8, C++ first. Features live in `Plugins/Features/<Area>/`. Shared contracts live
  in `Plugins/Core/JamCore` and change only additively.
- `main` must always build and run. The integration gate rejects any branch that breaks it.
- Every logic feature has an automation test `Project.<Area>.<Name>`.
- Binary assets are generated by committed scripts in `Content/Python/` and locked with `jf lock`
  before editing.
- Design source of truth: `docs/GDD.md`. Owner directives override it. Schedule: `docs/PLAN.md`.
- Jam rules: `docs/JAM.md`. Every external asset has a license that allows a published game and a
  row in `docs/CREDITS.md`; pre-jam tools are declared in `docs/PREMADE.md`; agents never publish.
- Art direction: `docs/art/STYLE.md` (written by the planner from the jam theme).
- English only: files, player-facing text, commit messages and board text. The merge gate rejects
  non-English lines; translate any you find.
